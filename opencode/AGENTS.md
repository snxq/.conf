# 全局工作约定（所有项目默认）

> 本文件是全局默认。项目里的 `AGENTS.md`、README 或规范文档优先于本文件。

## 沟通
- 默认用中文回答；代码、命令、报错信息保留原文。
- 先给结论，再给细节；不确定就说不确定，不要编造。

## 动手改代码之前
- 先读相关代码、项目结构和现有规范，理解风格再动手；先搜索是否已有可复用的实现。
- 遵循项目现有的框架、目录、命名和依赖；不擅自引入新依赖或重构无关代码。
- 改动保持小而聚焦；不要删除或重写来路不明的代码和文件——那可能是别人正在做的工作。

## 改完之后
- 运行受影响范围的测试、lint、typecheck，并说明结果；修到通过，或解释失败原因。
- 汇报说明：改了什么、为什么、怎么验证；有行为变化时给出前后对比。

## Git
- 不要主动 commit / push / rebase / reset，除非明确要求。
- 不提交密钥、token、.env 等敏感文件；提交前先看 diff。

## 安全与破坏性操作
- 不读取、不打印、不外传密钥文件内容；需要时用环境变量或占位符。
- 删数据、批量重命名、强制覆盖等破坏性操作，先说明后果再执行。
